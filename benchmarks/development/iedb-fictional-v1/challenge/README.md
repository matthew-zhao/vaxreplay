# Fictional IEDB-shaped compatibility challenge

This directory is a model-facing sealed-runner compatibility fixture. Every task, identifier,
evidence item, candidate, and outcome is project-authored and fictional. It contains no IEDB
records and is not scientific or medical evidence.

The fixture exercises submission packaging, temporal filtering, deterministic scoring, and receipt
verification. It does not measure real vaccine-development capability.
